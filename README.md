# Mistral

### Open-source language models from Mistral AI

Mistral offers a family of open-weight language models that punch well above their weight class. From the efficient 7B model to the powerful Mixtral 8x22B, Mistral models deliver exceptional performance per parameter.

<br>

---

## Features

| | |
|:---|:---|
| **Efficient Architecture** | Best-in-class performance at 7B and 8x7B parameter scales |
| **Apache 2.0** | Truly open — free for commercial use, modification, and redistribution |
| **Function Calling** | Native support for tools and JSON-mode structured outputs |
| **Long Context** | Extended context windows for processing lengthy documents and codebases |
